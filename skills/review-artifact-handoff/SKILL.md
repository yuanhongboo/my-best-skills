# 移交审阅材料

确认审阅问题、预期读者和获准提供的材料。用最小文件集呈现变更、必要上下文和可复核的证据。检查压缩包内的实际文件名，剔除凭据、个人资料、运行日志和与本次评审无关的原稿。如包内还有附件，逐层确认实际内容。

在说明中列出材料版本、关键问题、需要独立判断的部分及如何运行相关检查。在对方的可用环境中验证引用或给出可读替代材料。原始数据受限时，提供合成示例并标明其覆盖范围。

用户要求准备材料时交付文件和阅读顺序。获准发到指定目的地后，再记录接收方返回的版本或回执。上传完成、审阅开始、审阅意见返回分别记录。中断后先核对已有提交再决定是否重试。
