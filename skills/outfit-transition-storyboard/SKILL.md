# 多造型换装分镜

根据用户提供的角色设定、服装、参考图和时长，交付首帧的画面说明及与其匹配的分镜。用户只要求挑选造型或替换某段过渡时，仅完成该环节。

1. **锁定角色与空间。** 记录参考中可见的发型轮廓、饰品、身形比例、站姿和镜头视角。国籍、族裔等信息只有用户为角色设定时才使用。为每套造型分配可识别的名字和首帧位置，例如“墨绿短外套／画面左下”。明确哪些元素跨造型恒定，哪些会随服装改变。
2. **检查首帧是否能接动作。** 给每个可点击或将移动的小人物单独留白；避免袖口、脚尖或轮廓与邻人重叠。写清出发位置、移动后原位是否留空以及中央保留几个人物。这样下一帧才能延续第一张图。
3. **选过渡。** 遮挡转场需要真实能盖住剪切点的袖摆、折扇或前景。配对动作需要前后相同的头部方向、肩线和重心。点选飞入适合展示来源与目标的对应关系，明确谁移动、谁留在原位。
4. **编排时间表。** 每段写清开始姿势、触发拍点、切换服装的一瞬、落定姿势和镜头变化。按用户给出的总时长容纳预备与停留；要减少时长时优先减少套数或动作，保留辨认服饰的时间。
5. **输出。** 首帧生成提示与时间表使用同一套造型名称。另给下游视频生成器一段精简描述，覆盖背景、角色连续性、节奏和最后一帧。首尾姿势、服装数量与位置必须能逐段对上。

一个两拍例子：角色右手抬至胸前，左侧丝巾由前景经过；覆盖领口的一拍切换外套，丝巾退出时右手仍在胸前。第二拍再放下右手，给观众时间看清新的肩线。
