# 从资料建立知识地图

先写清这次要回答的问题、用户会用结论作什么选择，以及适用的地域和时间范围。为每个候选来源记录名称、出处、观察日期、可支持的论点和局限。公司自述、用户体验和独立测量各自注明。

从少数可比对象开始建立相同字段，例如服务对象、使用场景、价格口径或数据范围。相同词在不同来源含义不同时先校准定义。发现冲突时并列原始证据，保留仍可改变结论的问题。

将条目组织为一张问题索引和若干知识页。每页围绕一个读者问题给出有出处的回答，并注明哪些判断依赖当前时间。后续更新只复核存在变动的字段，登记本次更正、依据和日期。

交付示例：从“团队如何选择一种协作工具”进入，链接到权限、导出和离线能力三页。每个能力都对应可查的文档或试用观察。缺少实测的项目保留待验证标记。
