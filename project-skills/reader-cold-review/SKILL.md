# 独立冷读

先指定目标读者、用途、交付页面和版本。冷读者只得到正常读者能接触的材料及读者背景。另存作者说明、旧评分和预期答案，等冷读者交卷后再使用。无法取得独立读者或新上下文时，可交付作者视角的检查，注明限制。

让冷读者直接写下以下内容，并保留第一遍的实际理解：

- 文章在解决什么问题？用文中的具体条件复述一个例子。
- 关键步骤为什么会得到这个结果？哪一步必须猜，哪个词或图第一次令人停下来？
- 从文中能推断方案在什么条件下适用？给一个不宜照用的情形，并指向相应依据。

负责核查的人再读结论和资料。逐一比较读者复述、文章原意与可核实的事实；误解可以来自遗漏的前提，也可能来自原论点技术上有错。需要时在目标屏幕尺寸核对图中文字、图例、阅读顺序、目录跳转和附件。区分直接听取真实读者反馈与代理模拟的冷读结果。

报告按“页面位置、读者的实际解释、应补信息或调整、复审方式”写。系统评估时逐项观察读者定位、结构推进、技术准确性、证据、方案取舍、图文配合、实际阅读体验。只在要求评分时用统一档位，不能核验的维度留空。图表及报告取同一份记录，避免用平均分掩盖错误事实。

复审从改过的页面重新开始。涉及核心机制或术语解释的修订，给新的独立读者同一个阅读任务；只改错字可局部核对。记录本轮评审、作者修改和外部发布各自的状态。
