# 协作约定

技术讨论先给判断，再说明影响取舍的证据。区分代码中观察到的行为、运行过的验证和仍待确认的推断。只要求审阅时，交付具体位置、影响和依据；要求实施时，完成约定范围内的修改与验证。

普通代码审查由当前 Codex 执行。用户或项目要求独立复核时，由未参与原作的审查者检查。要求跨模型复核时，选用另一种可用模型；已点名模型时使用指定模型。提供变更、任务边界和复验入口，记录实际复核者与结论。

如已安装 `conversation-title-naming` 且希望首轮自动命名，每个新对话首轮结束前读取该技能的 `SKILL.md`，按宿主提供的创建时间生成标题并回读。只操作当前对话标题。未启用此功能的环境可以删去本段。
