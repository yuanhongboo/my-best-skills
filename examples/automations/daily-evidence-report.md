# 周期报告工单

输入为本次业务日期、允许读取的来源、筛选条件及上一期可核实的记录。在开始前明确本次交付是报告、入队还是实际投递。

1. 记录可访问的来源及覆盖期。某一来源读取失败时列出缺口；所有来源失败时报告采集故障。只有完成筛选且覆盖充分，才能给出“本期没有符合项”。
2. 对重复条目使用稳定标识。在沿用上一期事实之前，复核会随时间变化的字段。把新增、已变更、尚待核实的条目分开。
3. 生成报告后记录对应版本。如果任务包含入队，为同一业务日期和版本查重。若已有成功回执，沿用该回执；遇到上次结果不明，先查状态。
4. 将报告覆盖、入队结果和目标方回执分别写入交付说明。使用者只要求报告时，交付到报告这一步。
